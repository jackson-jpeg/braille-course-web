## Done and verified live

### 1. Domain (Vercel project setting, done through the Mac's logged-in Vercel CLI and API)

- Before: `teachbraille.org` had a redirect to `www.teachbraille.org` with no status code set, so Vercel
  sent a 307.
- Now: the apex has no redirect, and `www.teachbraille.org` sends a **308** to `teachbraille.org`.
- Canonicals were not changed. CLAUDE.md now records the apex as the one home, so nobody flips it back.

### 2. Verification (`scripts/seo/check-indexing.py`, run after the deploy)

- `sitemap.xml` returns 200 with 26 URLs; `robots.txt` returns 200 and names the apex sitemap.
- All **26 of 26** sitemap URLs return **200 with no redirect**, and each page's canonical equals its own
  URL.
- All 26 www versions return **308** to the matching apex URL.
- `http://teachbraille.org` gets a 308 to https. `http://www...` takes two hops (https, then apex), which
  is Vercel's standard behaviour and fine for Google.
- Re-run anytime: `python3 scripts/seo/check-indexing.py`. It exits 1 on any failure.

### 4. Course funnel (/learn prev/next)

- **No skipped or wrong Previous/Next links.** I checked all 18 lessons live: every lesson links to its
  neighbours in course order, lesson 1's Previous goes to course home, and wrap-up's Finish goes to course
  home. That's now held by a test (`__tests__/course/navigation.test.tsx`), which also follows Next from
  lesson 1 and must visit every lesson exactly once.
- **One real bug fixed:** the course home's **Resume** button reopened the last lesson you touched, even
  after you'd finished it (its own code comment said "first unfinished lesson"). It now goes to the first
  unfinished lesson from where you left off. The old code fails the new tests.
- **On the numbers:** navigation doesn't explain 122 on letters-k-t versus 67 on letters-u-z. The more
  likely story is search entrances: reading-words (more visitors than u-z) is a page people search for
  directly. I haven't verified that against the analytics, though; per-page referrers in Vercel Analytics
  would show it.
