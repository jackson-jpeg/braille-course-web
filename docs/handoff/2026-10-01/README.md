**Where this ran:** every command in this session ran in a Claude Code cloud container (Linux), not on the VPS or
MacBook. Nothing was run on either machine. These files live in the repo at `docs/handoff/2026-10-01/`; copy the

**Deploy path (found in recon):** GitHub `jackson-jpeg/braille-course-web` → Vercel git integration. Pushes to

checkout + webhook, Resend email, Vercel Blob, two Vercel crons. No CI workflows in the repo.

## What shipped

### 1. UEB accuracy foundation

- `lib/ueb.ts` is now the single source of truth for every cell on the site (letters, digits, indicators, 15
  punctuation signs, 62 contractions) plus an uncontracted transcriber. All older maps are derived from it.
- Contracted (grade 2) braille is never hand-built: it comes from liblouis output stored in `lib/data/ueb-contracted.json`.
- `__tests__/lib/ueb.test.ts` checks everything twice: against the official chart (typed as Unicode) and against
  liblouis 3.29 (`__tests__/fixtures/ueb-oracle.json`, regenerated by `scripts/generate-ueb-oracle.ts`). It also scans
  the source so even decorative braille words are verified.
- **Live bugs this caught and fixed:** Contraction Sprint built 22 of 68 words wrong (e.g. "child" as four cells);
  Sentence Decoder mixed contractions with spelled-out words (not valid UEB); Number Sense's Nemeth equals sign and
  numeric indicators were wrong; Dot Explorer said dot 1 was "1" not "a"; Bingo printed each letter next to its cell.

### 2. Totally fresh design ("Raised")

- Six-dot cell as the core visual system: cell logo, buttons with tiny braille cells, cell loaders, eyebrow labels
  spelled in braille, dot-lattice paper texture, stars made of filling cells, tactile press-down buttons.
- Palette ink / paper / tomato-red dots / pine / marigold, all contrast-checked. Fonts: Bricolage Grotesque +
  Atkinson Hyperlegible (designed by the Braille Institute for low-vision readers).
- Every public page rebuilt: home, lessons, games hub + 17 game pages, alphabet guide, courses, services,
  appointments, policies, checkout, success, 404, error, loading, OG image, favicons. Design doc: `docs/DESIGN.md`.
- Admin keeps its working layout, re-themed to the new palette (old CSS isolated to `/admin`).

### 3. Games: 17 total (5 new), each at `/games/<slug>`

- New: **Dot Quest** (kid adventure: islands, stars, sticker book), **Letter Race**, **Dot Builder**,
  **Word Decoder** (letters → numbers → punctuation → capitals → sentences), **Contraction Trainer** (spaced review).
- All 12 existing games rebuilt on a shared accessible kit: full keyboard play, Perkins keys (F D S J K L),
  screen-reader announcements, untimed/relaxed modes, ✓/✗ not color-only.
- Progress (localStorage v3): streaks, achievements, per-letter/contraction skill memory, quest stars/stickers,
  and a "what to practise next" recommender shown on home, lessons and games.

### 4. Lessons: 12-lesson beginner track at `/learn`

What braille is → the cell → a–j → k–t → u–z → first words → numbers → punctuation → capitals → first
contractions → more shortcuts → next steps (points to Delaney's courses). Each lesson has a write drill, a read
drill or quiz, a "mark done", and a link into its matching game with the right settings.

### 5. Courses are evergreen

- `/courses` replaces `/summer` (301). No dates or prices shown. "Join the list" posts to the same
  `/api/waitlist-signup` lead capture as before. Public Stripe enrollment appears only when `lib/cohort.ts` has a
  real cohort. Checkout API, webhook, crons, admin: logic unchanged.

### 6. SEO

Titles, descriptions, canonicals and JSON-LD on every page; sitemap lists all lessons and games; 301s for `/summer`
and 8 old lesson URLs; old `/games#anchor` links forward to the new game pages.
